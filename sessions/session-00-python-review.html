python refresher for spatial analysis

Warm-up before we touch a single raster or shapefile

Before we open a single satellite image or elevation model, we need to make sure everyone speaks the same Python language. This session is not about GIS itself. It is about the small set of Python tools that every single session in this course will lean on. Nothing here is random. Every example was picked because you will see the exact same pattern again later, when you calculate NDVI, slope, camera parameters, or filter road networks.

NoteHow to use this notebook

Read the explanation, run the example, then try the exercise before looking at the solution. Solutions are hidden inside a collapsible box. Click to reveal them only after you have tried on your own.

Variables, Lists, and Dictionaries

In spatial work, almost everything is a bunch of numbers with a label attached to it: pixel values, band names, coordinate systems, ground control point coordinates, weights used in a model. Lists and dictionaries are the two basic Python structures used to organize that kind of information.

Variables

A variable is simply a name that points to a value. The value can be a number, text, or something more complex. Let’s start with something familiar from surveying: a single ground control point (GCP) used in photogrammetry to align an aerial photo with real world coordinates.

gcp_name = "GCP-01"
gcp_x = 512340.25
gcp_y = 3891220.10
gcp_elevation = 812.4

print(gcp_name, "is located at elevation", gcp_elevation, "meters")
GCP-01 is located at elevation 812.4 meters
# Example 2: a camera parameter used in photogrammetry
focal_length_mm = 35
sensor_width_mm = 23.5
image_width_px = 6000

# Ground sample distance depends on all three parameters
flying_height_m = 1200
gsd_cm = (sensor_width_mm * flying_height_m * 100) / (focal_length_mm * image_width_px)
print("Ground sample distance:", round(gsd_cm, 2), "cm/pixel")
Ground sample distance: 13.43 cm/pixel

Dictionaries

A dictionary stores key and value pairs. Instead of creating several separate variables, a dictionary keeps related information together under one name. In Session 3, rasterio will return raster metadata in exactly this format.

raster_metadata = {
    "filename": "sentinel.tif",
    "width": 512,
    "height": 512,
    "crs": "EPSG:32639",
    "bands": 4
}

print("This raster uses CRS:", raster_metadata["crs"])
print("Dimensions:", raster_metadata["width"], "x", raster_metadata["height"])
This raster uses CRS: EPSG:32639
Dimensions: 512 x 512
# Dictionary methods that matter most
print(raster_metadata.keys())
print(raster_metadata.values())
print(raster_metadata.items())

# safely get a value that might not exist
print(raster_metadata.get("nodata", "not specified"))

# update or add a key
raster_metadata["nodata"] = -9999
print(raster_metadata)
dict_keys(['filename', 'width', 'height', 'crs', 'bands'])
dict_values(['sentinel.tif', 512, 512, 'EPSG:32639', 4])
dict_items([('filename', 'sentinel.tif'), ('width', 512), ('height', 512), ('crs', 'EPSG:32639'), ('bands', 4)])
not specified
{'filename': 'sentinel.tif', 'width': 512, 'height': 512, 'crs': 'EPSG:32639', 'bands': 4, 'nodata': -9999}
# A nested dictionary example: metadata for several photogrammetry cameras
cameras = {
    "camera_A": {"focal_length_mm": 35, "sensor_width_mm": 23.5},
    "camera_B": {"focal_length_mm": 50, "sensor_width_mm": 36.0}
}

for camera_name, specs in cameras.items():
    print(f"{camera_name}: focal length {specs['focal_length_mm']} mm")
camera_A: focal length 35 mm
camera_B: focal length 50 mm
TipNote: dictionaries versus lists

Use a list when order matters and items are of the same kind, such as a series of elevation readings. Use a dictionary when you need to label each value, such as raster metadata or camera specifications.

A. dictionary.keys()

Functions

Almost every session in this course ends with writing one function, such as calculate_ndvi, calculate_slope, or calculate_final_score. Becoming comfortable with functions now will remove a lot of confusion later.

A basic function

def celsius_to_fahrenheit(celsius):
    """Convert a temperature from Celsius to Fahrenheit."""
    fahrenheit = (celsius * 9 / 5) + 32
    return fahrenheit

print(celsius_to_fahrenheit(21.5))
70.7

Functions with default parameters

def classify_elevation(elevation_m, threshold=800):
    """Return 'high' or 'low' depending on a threshold."""
    if elevation_m > threshold:
        return "high"
    return "low"

print(classify_elevation(860))
print(classify_elevation(790))
print(classify_elevation(860, threshold=900))
high
low
low
TipNote: default parameters

threshold=800 means use 800 unless the caller specifies otherwise. This exact pattern appears again in Session 8, where the suitability function has default weights that a student can later override.

Functions that return multiple values

def image_stats(pixel_values):
    """Return the minimum, maximum, and average of a list of pixel values."""
    minimum = min(pixel_values)
    maximum = max(pixel_values)
    average = sum(pixel_values) / len(pixel_values)
    return minimum, maximum, average

pixels = [120, 98, 145, 132, 110, 156]
low, high, avg = image_stats(pixels)
print("Min:", low, "Max:", high, "Average:", round(avg, 2))
Min: 98 Max: 156 Average: 126.83

Functions that call other functions

def dn_to_reflectance(dn_value, gain=0.0001, offset=0.0):
    """Convert a digital number to reflectance using a linear model."""
    return dn_value * gain + offset

def classify_reflectance(reflectance, threshold=0.2):
    """Classify a reflectance value as vegetation or non-vegetation."""
    if reflectance > threshold:
        return "vegetation"
    return "non-vegetation"

digital_number = 2500
reflectance_value = dn_to_reflectance(digital_number)
label = classify_reflectance(reflectance_value)

print(f"DN {digital_number} corresponds to reflectance {reflectance_value:.3f}, classified as {label}")
DN 2500 corresponds to reflectance 0.250, classified as vegetation

Applying a function to a whole list

def classify_all(elevation_list, threshold=800):
    """Classify every elevation value in a list."""
    results = []
    for value in elevation_list:
        results.append(classify_elevation(value, threshold))
    return results

elevations = [812, 790, 845, 803, 860, 798]
print(classify_all(elevations))
['high', 'low', 'high', 'high', 'high', 'low']

From Lists to NumPy Arrays

This is the single most important concept in this session. A raster, whether it is a satellite image or an elevation model, is nothing more than a large NumPy array of numbers. Every calculation performed in later sessions, including NDVI, slope, aspect, and the final suitability score, is simply NumPy math applied to arrays.

The problem with plain lists

elevations = [812, 790, 845, 803, 860, 798]

# converting every value to feet forces a manual loop with a plain list
elevations_ft = []
for value in elevations:
    elevations_ft.append(value * 3.281)

print(elevations_ft)
[2664.172, 2591.9900000000002, 2772.445, 2634.643, 2821.6600000000003, 2618.2380000000003]

The NumPy way

import numpy as np

elevations = np.array([812, 790, 845, 803, 860, 798])

# multiplication now applies to every value at once, no loop needed
elevations_ft = elevations * 3.281
print(elevations_ft)
[2664.172 2591.99  2772.445 2634.643 2821.66  2618.238]
TipNote: vectorized operations

When an operation applies to a whole array at once, without an explicit loop, this is called a vectorized operation. This is not only shorter code, it is dramatically faster, which matters when the array is an image with millions of pixels.

Creating arrays with built-in functions

zeros_array = np.zeros(5)
ones_array = np.ones(5)
sequence_array = np.arange(0, 50, 10)
even_spacing = np.linspace(0, 1, 5)

print("Zeros:", zeros_array)
print("Ones:", ones_array)
print("Arange:", sequence_array)
print("Linspace:", even_spacing)
Zeros: [0. 0. 0. 0. 0.]
Ones: [1. 1. 1. 1. 1.]
Arange: [ 0 10 20 30 40]
Linspace: [0.   0.25 0.5  0.75 1.  ]

These functions are commonly used to create placeholder arrays before filling them with real raster values, or to generate evenly spaced coordinates along a flight line.

Filtering with conditions

elevations = np.array([812, 790, 845, 803, 860, 798])

Two dimensional arrays

A raster is a grid of numbers, which in NumPy is represented as a two dimensional array. Imagine the grid below as a small elevation model.

dem = np.array([
    [812, 815, 818, 820, 825],
    [805, 808, 812, 818, 822],
    [795, 798, 802, 808, 815],

WarningNote: rows versus columns

In NumPy, and in every raster used later, the first index is the row (the y direction, top to bottom) and the second index is the column (the x direction, left to right). This is one of the most common beginner mistakes, so keep it in mind starting from Session 3.

Quick quiz

Question 3

Why are NumPy arrays preferred over plain Python lists when working with raster data?

A. NumPy arrays use less disk space than lists

B. NumPy arrays support fast, vectorized math without explicit loops

C. Lists cannot store numbers, only text

D. NumPy arrays automatically carry a coordinate system

Answer B. The real power of NumPy for this course is vectorized operations: applying math to millions of pixels at once with no loop required. Option D is tempting but incorrect. A plain NumPy array has no geographic information attached; that is what a library such as rasterio adds later.

Working with Files and Paths

Starting from Session 1, the project will have a real folder structure, including data, data/outputs, and modules. A reliable way of building file paths is needed that works the same way on Windows, Mac, and Linux.

The pathlib way

from pathlib import Path

data_folder = Path("data")
outputs_folder = data_folder / "outputs"
ndvi_path = outputs_folder / "ndvi.tif"

print(ndvi_path)
print("Does this file exist:", ndvi_path.exists())
data/outputs/ndvi.tif
Does this file exist: False
TipNote: the slash operator

The / symbol joins path pieces together when used with pathlib. It automatically uses the correct separator for the operating system, so the same code works on any computer.

Useful path attributes and methods

print("Name:", image_path.name)

Listing and creating folders

data_folder = Path("data")

if data_folder.exists():

C. import.meters_to_feet(500)

D. It cannot be called this way, this import style is only for classes

Answer B. When a specific function is imported with from module import function_name, it is called directly by name, with no module prefix needed. Option A would be correct only if import unit_converter had been used instead.
