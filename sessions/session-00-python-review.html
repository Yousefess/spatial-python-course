Python Review

Welcome

Before we open a single satellite image or elevation model, we need to make sure everyone speaks the same Python language. This session is not about GIS — it is about the small set of Python tools that every single session in this course will lean on.

Nothing here is random. Every example was picked because you will see the exact same pattern again later — when you calculate NDVI, slope, or filter road networks.

NoteHow to use this notebook

Read the explanation, run the example, then try the exercise before looking at the solution. Solutions are hidden — click to reveal them only after you have tried.

1. Variables, Lists, and Dictionaries

Why this matters

In this course, almost everything is “a bunch of numbers with a label” — pixel values, band names, coordinate systems, weights for our final model. Lists and dictionaries are how Python organizes that.

Example 1.1 — Variables

# A single weather station reading
station_name = "Station A"
temperature_celsius = 21.5
elevation_m = 1250

print(f"{station_name} is at {elevation_m} m, temperature: {temperature_celsius}°C")

Example 1.2 — Lists

# Elevation readings (in meters) from 5 weather stations
elevations = [1250, 980, 1430, 1100, 1600]

print("Number of stations:", len(elevations))
print("Highest station:", max(elevations))
print("Lowest station:", min(elevations))

Example 1.3 — Looping through a list

# Print each station's elevation with its index
for index, value in enumerate(elevations):
    print(f"Station {index + 1}: {value} m")

Example 1.4 — Dictionaries

# A dictionary is perfect for storing metadata — something we will do a lot
raster_metadata = {
    "filename": "sentinel.tif",
    "width": 512,
    "height": 512,
    "crs": "EPSG:32639",
    "bands": 4
}

print("This raster uses CRS:", raster_metadata["crs"])
TipWhy dictionaries instead of separate variables?

Instead of creating width, height, crs, bands as four separate variables, a dictionary keeps everything related together, under one name. In Session 3, you will see rasterio return metadata in exactly this dictionary format.

2. Functions

Why this matters

Almost every session in this course ends with you writing one function: calculate_ndvi(), calculate_slope(), calculate_final_score(). Getting comfortable with functions now saves a lot of confusion later.

Example 2.1 — A basic function

def celsius_to_fahrenheit(celsius):
    """Convert a temperature from Celsius to Fahrenheit."""
    fahrenheit = (celsius * 9 / 5) + 32
    return fahrenheit

print(celsius_to_fahrenheit(21.5))

Example 2.2 — A function with multiple parameters

def classify_elevation(elevation_m, threshold=1200):
    """Return 'high' or 'low' depending on a threshold."""
    if elevation_m > threshold:
        return "high"
    else:
        return "low"

print(classify_elevation(1600))
print(classify_elevation(900))
print(classify_elevation(1600, threshold=2000))
TipDefault parameters

threshold=1200 means “use 1200 unless the caller says otherwise.” You will use this exact pattern in Session 8, when the suitability function has default weights that a student can later override.

Example 2.3 — A function that works on a whole list at once

def classify_all(elevation_list, threshold=1200):
    """Classify every elevation in a list."""
    results = []
    for value in elevation_list:
        results.append(classify_elevation(value, threshold))
    return results

elevations = [1250, 980, 1430, 1100, 1600]
print(classify_all(elevations))

Example 2.4 — Function with multiple return values

def elevation_stats(elevation_list):
    """Return min, max, and mean of a list of elevations."""
    return min(elevation_list), max(elevation_list), sum(elevation_list) / len(elevation_list)

elevations = [1250, 980, 1430, 1100, 1600]
min_elev, max_elev, mean_elev = elevation_stats(elevations)
print(f"Min: {min_elev}, Max: {max_elev}, Mean: {mean_elev:.1f}")

3. From Lists to NumPy Arrays

Why this matters

This is the single most important concept in this session. A raster (satellite image, elevation model) is nothing more than a big NumPy array of numbers. Every calculation you do in Sessions 4 to 8 (NDVI, slope, aspect, suitability score) is just NumPy math on arrays.

Example 3.1 — The problem with plain lists

elevations = [1250, 980, 1430, 1100, 1600]

# With a plain list, you are forced to loop:
elevations_ft = []
for value in elevations:
    elevations_ft.append(value * 3.281)

print(elevations_ft)

Example 3.2 — The NumPy way

import numpy as np

elevations = np.array([1250, 980, 1430, 1100, 1600])

# Now multiplication applies to every value at once — no loop needed
elevations_ft = elevations * 3.281
print(elevations_ft)
TipVectorized operations

When an operation applies to a whole array at once (no loop), we call it vectorized. This is not just shorter code — it is dramatically faster, which matters a lot when your “list” is actually an image with millions of pixels.

Example 3.3 — Filtering with conditions

elevations = np.array([1250, 980, 1430, 1100, 1600])

# Boolean mask: True/False for each value
above_1200 = elevations > 1200
print(above_1200)

# Use the mask to actually pull out the values
print(elevations[above_1200])

# Or in one line:
print(elevations[elevations > 1200])
TipThis is exactly how we will pick “good” pixels

In Session 5, we will write something like slope_array[slope_array < 10] to find every pixel with a gentle enough slope for solar panels. Same exact pattern you just used.

Example 3.4 — 2D arrays (this is basically a mini raster)

# Imagine this 5x5 grid of numbers is a tiny elevation model (DEM)
dem = np.array([
    [1200, 1210, 1215, 1220, 1225],
    [1190, 1195, 1205, 1215, 1230],
    [1180, 1185, 1190, 1200, 1210],
    [1150, 1160, 1170, 1180, 1195],
    [1100, 1120, 1140, 1160, 1175]
])

print("Shape of this 'DEM':", dem.shape)
print("Value at row 2, column 3:", dem[2, 3])

Example 3.5 — Slicing a 2D array

# Get the top-left 2x2 corner
print(dem[0:2, 0:2])

# Get the entire first row
print(dem[0, :])

# Get the entire last column
print(dem[:, -1])

Example 3.6 — Applying a condition to a 2D array

# Which pixels are above 1200 m?
high_pixels = dem > 1200
print(high_pixels)

# How many pixels are above 1200 m?
print("Count:", np.sum(high_pixels))

# What is the average elevation of the whole grid?
print("Mean elevation:", np.mean(dem))

Example 3.7 — Basic array math

# Create two arrays and perform element-wise operations
array1 = np.array([10, 20, 30, 40])
array2 = np.array([1, 2, 3, 4])

print("Addition:", array1 + array2)
print("Multiplication:", array1 * array2)
print("Power:", array1 ** 2)
WarningRows vs. columns

In NumPy (and in every raster you will work with), the first index is the row (y-direction, top to bottom) and the second index is the column (x-direction, left to right). Mixing these up is one of the most common beginner mistakes.

4. Working with Files and Paths

Why this matters

Starting from Session 1, your project will have a real folder structure (data/, data/outputs/, modules/). You need a reliable way to build file paths that works on any computer — Windows, Mac, or Linux.

Example 4.1 — The problem with hardcoded paths

# Do not do this — it breaks on other operating systems
# path = "data\\outputs\\ndvi.tif"   # Windows-style, breaks on Mac/Linux
# path = "data/outputs/ndvi.tif"     # works on Mac/Linux, awkward on Windows

Example 4.2 — The pathlib way

from pathlib import Path

data_folder = Path("data")
outputs_folder = data_folder / "outputs"
ndvi_path = outputs_folder / "ndvi.tif"

print(ndvi_path)
print("Does this file exist?", ndvi_path.exists())
TipThe / operator

Notice data_folder / "outputs" — with pathlib, the / symbol joins path pieces together. It automatically uses the correct separator (\ on Windows, / on Mac/Linux) so your code works everywhere.

Example 4.3 — Listing files in a folder

data_folder = Path("data")

# List all .tif files in the folder
if data_folder.exists():
    for file in data_folder.glob("*.tif"):
        print(file.name)

Example 4.4 — Creating folders safely

outputs_folder = Path("data/outputs")
outputs_folder.mkdir(parents=True, exist_ok=True)
print("Folder ready:", outputs_folder)
Tipexist_ok=True

Without this, Python raises an error if the folder already exists. With it, Python just moves on quietly — very useful when you re-run a notebook multiple times.

Example 4.5 — Getting file information

from pathlib import Path
from datetime import datetime

file_path = Path("data/sample.txt")

# Get file name, extension, and parent folder
print("File name:", file_path.name)
print("Stem (name without extension):", file_path.stem)
print("Extension:", file_path.suffix)
print("Parent folder:", file_path.parent)

# Check file properties if it exists
if file_path.exists():
    print("Size (bytes):", file_path.stat().st_size)
    print("Last modified:", datetime.fromtimestamp(file_path.stat().st_mtime))

5. Building and Importing Your Own Module

Why this matters

Starting in Session 1, every session produces a .py file inside a modules/ folder (data_loader.py, raster_utils.py, etc). By the end of the course, main.py and app.py will import and combine all of them. Let us practice that pattern right now, with something simple.

Example 5.1 — Creating a small module

Save this code in a file named unit_converter.py, in the same folder as your notebook:

# unit_converter.py

def meters_to_feet(meters):
    """Convert meters to feet."""
    return meters * 3.281

def celsius_to_fahrenheit(celsius):
    """Convert Celsius to Fahrenheit."""
    return (celsius * 9 / 5) + 32

def kilometers_to_miles(km):
    """Convert kilometers to miles."""
    return km * 0.621371

Example 5.2 — Importing it into your notebook

import unit_converter

print(unit_converter.meters_to_feet(1250))
print(unit_converter.celsius_to_fahrenheit(21.5))
print(unit_converter.kilometers_to_miles(100))

Example 5.3 — Importing specific functions

from unit_converter import meters_to_feet, kilometers_to_miles

print(meters_to_feet(500))
print(kilometers_to_miles(42))

Example 5.4 — Importing with an alias

import unit_converter as uc

print(uc.meters_to_feet(1000))
print(uc.celsius_to_fahrenheit(0))
WarningWhere should the module file live?

Python looks for unit_converter.py in the same folder as your notebook (or somewhere on its search path). If you get a ModuleNotFoundError, the most common cause is the file being in the wrong folder. Starting Session 1, we will organize this properly with a modules/ folder.

Exercise 5.2

Create a new module called stats_utils.py with two functions: - mean(numbers): returns the average of a list - median(numbers): returns the median of a list

Import and test both functions in your notebook.

Show solution

Create stats_utils.py:

def mean(numbers):
    """Return the mean of a list of numbers."""
    return sum(numbers) / len(numbers)

def median(numbers):
    """Return the median of a list of numbers."""
    sorted_nums = sorted(numbers)
    n = len(sorted_nums)
    if n % 2 == 1:
        return sorted_nums[n // 2]
    else:
        return (sorted_nums[n // 2 - 1] + sorted_nums[n // 2]) / 2

In your notebook:

from stats_utils import mean, median

data = [10, 20, 30, 40, 50]
print("Mean:", mean(data))
print("Median:", median(data))
